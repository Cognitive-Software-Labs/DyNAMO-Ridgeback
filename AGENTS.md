## Shared guidance

Read `docs/project/PROJECT_CONTEXT.md` for repository orientation before doing
substantial work, then read `docs/project/conventions.md`, which owns the
cross-cutting conventions and the graphify rules. Documentation ownership lives
in `docs/project/documentation.md`.

Read both files rather than relying on the project context to pull them in:
Claude Code inlines them through `@` imports, Codex does not.
