# torch / torchvision are the CUDA 12.8 (cu128) builds. The cu128 wheels carry
# the sm_120 kernels needed for Blackwell GPUs (e.g. RTX PRO 6000). The
# `+cu128` local-version pins force pip to fetch them from the PyTorch index
# below instead of the CPU-only wheels on PyPI — installing plain `torch` from
# PyPI is what silently runs Depth-Anything / OWLv2 on CPU.
#
# For a different GPU / CUDA toolkit, change the index URL (e.g. cu121, cu124)
# and the matching torch/torchvision versions.
